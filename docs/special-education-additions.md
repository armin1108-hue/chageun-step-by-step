## 1. 기존 앱을 기준으로 확장
학생용 여섯 화면(처음, 나의 하루, 마음 전하기, 말로 전하기, 생활 연습, 쉬어 가기)과 교사용 시연 기록을 유지한다. 기존 디자인을 재사용하고 공통 설정·교사 편집·관찰 모듈을 추가한다.
기존 앱은 브라우저 localStorage 데모이며 로그인·공동 저장·교사 알림이 구현되지 않았다. 현재 공개 데모의 활동 체크·감정 선택은 실제 교육 성취 또는 진단의 증거가 아니다.

## 4. 배포·운영 요구사항과 연결
사용자가 제공한 작업지시서 9~16항 및 D01~D12는 그대로 적용한다.
- 교사 관찰 본문·학생 지원 정보는 브라우저 영구 저장소·오프라인 캐시에 저장하지 않는다.
- 실제 기록은 승인된 서버 저장·초대 로그인·요청별 권한 확인이 마련된 뒤 사용한다.
- 학생용 공개 가상 활동과 교사 기록을 분리한다. 외부 프로그램의 계정 없음·로컬 저장 설계를 교사 기록 저장에 그대로 적용하지 않는다.
- 외부 AI는 기본 비활성화. 카드 선택 문장을 AI가 학생 동의 없이 대체하지 않는다.
- 실데이터 반출 없이 가상 자료로 시험하고 D01~D12 검수 결과·백업 복구·소유권·운영 인수인계를 별도 기록한다.
- 현재 main 커밋→자동 배포 방식은 운영 승인 요구와 차이가 있으므로 보호된 시험·운영 배포 절차를 추가한다.
- 전면 재개발 대신 기존 HTML/JS를 유지하는 확장 가능성을 먼저 검토한다. 인증·서버 저장은 별도 모듈과 명세로 추가한다.

## 5. 구현 순서와 남은 확인
1. 기존 핵심 흐름 회귀 확인 및 교사 편집 설정 설계.
2. A01~A04를 가상 자료로 확장.
3. A05 관찰·목표·문서 흐름 구현.
4. 인증·서버 저장·권한·백업 구성과 D01~D12 검수.
담당 과정·학년·우선 업무·사용 기기·학교 승인 저장 환경은 미확인이다. 외부 코드 통합, 새 기능 구현, 시험·운영 배포는 이 문서 작성만으로 완료되지 않는다.
