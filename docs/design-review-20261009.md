# 학생 중심 디자인 개선 검수

확인일: 2026-10-09 한국 시간. 기존 PR #1 공개 가상자료 시연에 추가한 개선이며 학교 운영 배포가 아니다.

## 변경 내용

- 기존 Stitch 교실 그림을 유지하고 크림·숲색 바탕, 큰 그림 카드 다섯 개, 짧은 문장과 일관된 메뉴를 적용했다. 새 픽토그램은 직접 작성한 SVG다.
- 학생 화면 여섯 개는 화면 크기에 맞춰 카드 배열이 바뀐다. 큰 조작 버튼, 명확한 초점 표시, 움직임 감소 설정을 유지한다.
- 일과는 지금/다음과 완료 상태를 구분하고, 감정은 자동 선택 없이 학생이 선택한 마음을 표시한다.
- 생활 연습은 그림과 현재 단계, 이전·듣기·다음에 집중한다. 자동 진행과 시간 제한은 없다. 휴대폰에서는 중복 안내와 음성 버튼을 줄였다.
- AAC는 그림 선택·원문 문장 조합·개별 삭제·전체 삭제·명시적 읽기를 유지한다. 휴대폰 첫 화면에서 첫 두 카드를 볼 수 있도록 안내와 문장 영역을 줄였다.
- 휴식 소리 버튼은 선택 상태를 aria-pressed로 전달하고 전체 소리 정지 시 재생·선택 표시를 함께 해제한다.
- 교사 화면은 오늘의 흐름, 수업 화면 편집, 관찰·목표 초안, 시연 기록으로 정리했다. 기존 입력·검토·확정 로직을 보존했다.

## 직접 확인한 결과

원격 Chrome 데스크톱 및 같은 브라우저 내 390px·820px 너비 프레임으로 확인했다. 너비 프레임은 실제 휴대폰·태블릿 검수를 대체하지 않는다.

| 확인 항목 | 결과 |
| --- | --- |
| 학생 홈 | 데스크톱 그림 카드 5열, 390px 화면 2열 배치·가로 넘침 없음 |
| 일과·감정·휴식 | 390px와 820px에서 문서 가로 넘침 없음 |
| AAC | 390px와 820px에서 가로 넘침 없음. 카드 두 개 조합·한 카드 삭제 정상 |
| 생활 연습 | 390px에서 현재 단계·이전/듣기/다음 표시. 다음→2단계, 이전→1단계 정상 |
| 교사 화면 | 데스크톱, 390px, 820px에서 가로 넘침 없음. 입력 16px·라벨 14px 확인 |
| 교사 설정 | 일과·AAC·생활 연습 설정 저장 및 학생 화면 반영 정상 |
| 일과 유지 | 첫 일과 표시 후 지금/다음 변경, 새로고침 후 유지 |
| 감정 선택 | 최초 미선택·읽기/크게 보기 비활성, 키보드 Enter 선택·새로고침 유지·확대 모달 열기/닫기 정상 |
| 휴식 소리 정지 | 소리 선택 후 재생 배지 표시, 헤더 전체 정지 후 배지·강조·aria-pressed 해제 확인 |
| 자동 검사 | 외부·인라인 JavaScript 구문 검사, 기존 핵심 자동 검사 9개, 정적 빌드 통과 |

한국어 음성의 실제 청취 품질, 스크린리더 전체 흐름, 200% 확대, 학교의 실제 기기·네트워크는 별도 검수가 필요하다. 타이머 종료의 소리 상태 정리는 코드로 보완했으며 실제 분 단위 대기 검수는 하지 않았다. 디자인 개선 자체를 교육 효과나 접근성 인증으로 표시하지 않는다.

## 유지되는 범위와 제한

실제 학생자료 입력 금지, 외부 AI 비활성화, 공개 가상자료 시연 상태를 유지한다. 설정·가상 활동 표시는 이 브라우저에만 저장되며 관찰 원문은 현재 탭의 메모리에만 있다. 운영 계정·인증·서버 저장·백업 등의 D01~D12 상태는 `additions-deployment-report.md`와 같다.

검수용 너비 프레임 페이지는 검수 후 배포 소스에서 제거한다. 기존 공개 main 사이트의 운영 설정이나 계정 권한은 변경하지 않았다.
