## 구현한 추가 기능

학생용 여섯 화면과 기존 활동 시연 기록을 유지했다. 교사 화면에 일과·AAC·활동·움직임 설정과 가상 관찰·목표 문서 작성 기능을 추가했다.

| 항목 | 구현·확인 결과 | 남은 검수·기능 |
|---|---|---|
| A01 AAC | 여덟 카드의 문구·기호·분류 편집, 고정 위치, 문장 조합·개별 삭제·전체 삭제·명시적 읽기·소리 중지. 편집 내용이 학생 화면에 반영되는 것을 확인 | 실제 기기에서 한국어 음성 품질·터치·키보드 전체 흐름 확인 |
| A02 일과 | 이름·안내·기호·순서·변경 안내 편집, 지금/다음 표시. 체크 후 새로고침 유지 확인 | 학생 체크와 별도로 저장되는 교사 확인 필드·서버 저장 미구현 |
| A03 단계 활동 | 이름·다섯 단계·지원 방법 편집, 이전/다음/다시 듣기. 첫 단계 이전 버튼 비활성화와 단계 이동 확인. 자동 타이머 제거 | 지정 기기·학생 사용성 검수 |
| A04 감정·휴식 | 감정 선택 건너뛰기, 움직임 감소, 소리 중지. 기존 도움 요청은 화면 표시이며 실제 교사 전송 아님 | 학교의 도움 요청 대응 담당자·알림 절차 확정 |
| A05 관찰 문서 | 가상 학생·교사 선택, 수행 근거·목표·확인 방법·검토일·관찰·도움·환경 직접 입력. 원문 보존, 검토 체크 전 확정 거절, 검토 후 확정, 수정 시 확정·인쇄 해제 확인 | 서버 저장·재접속 조회 없음. 인쇄 버튼 실행을 확인했으나 이 검수 브라우저에서 OS 인쇄 창·출력물은 확인하지 못함 |
| A06 공통 | 초점 표시·조작 영역·움직임 감소·반응형 CSS·문서 인쇄 CSS 적용 | 휴대폰·태블릿 실제 기기, 200% 확대, 학교 네트워크, 접근성 종합 검수 미실시 |

수업 설정·가상 활동은 해당 브라우저의 localStorage에만 저장된다. 관찰·목표 원문은 현재 탭의 메모리에만 유지되며 새로고침·종료 후 사라진다. 관찰 초안 생성은 서버 저장 성공을 뜻하지 않는다. 교사 편집도 다른 기기나 다른 브라우저로 동기화되지 않는다.

## 확인 방법과 증빙

- `npm test`: 외부·인라인 JavaScript 구문 검사 및 9개 자동 검사. 설정 유지·손상 복구·저장 실패 시 상태 유지·입력 검증·관찰 원문 보존·교사 검토·관찰의 영구 저장 차단을 포함.
- `npm run build`: `web/`만 `dist/`로 복사하는 정적 빌드. 원본 Stitch 자료는 배포하지 않음.
- GitHub Actions: PR의 Node 22 검사·빌드. Netlify도 검사 실패 시 빌드를 중단하도록 구성.
- 배포 화면: 공개 시연 주소에서 가상 자료만 사용. 일과·AAC·활동 편집과 학생 화면 반영, 새로고침 유지, AAC 조합·삭제, 단계 이동, 관찰 원문 표시·검토·확정·수정 후 해제를 직접 확인.
- 사용 환경: 원격 Chrome 데스크톱 검수. 선생님의 실제 기기·브라우저 버전·학교 네트워크 검수는 별도 수행 필요.

위 결과는 접근성 인증·교육 효과·진단 정확성·학교 운영 보안 인증을 의미하지 않는다. GitHub에서 참고한 외부 코드·그림·스킬은 복사·설치하지 않았으며 미국 제도나 자폐 관련 효과 주장을 국내 학생에게 자동 적용하지 않았다.
