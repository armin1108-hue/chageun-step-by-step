[1. 무료 ChatGPT: 수업 목표를 Stitch 요청문으로 바꾸기]
특수교사 연수에서 쓸 수업 화면 요청문을 만들어 주세요.
앱 이름: 차츰차츰
대상: [학년, 읽기·선택·조작 지원 요구를 교사가 입력]
활동: 책상 정리. 목표: 책과 필통을 제자리에 놓는다.
흐름: 처음 → 활동 안내(책 넣기/필통 놓기/책상 확인) → 완료·다시 시도.
활동 안내는 한 번에 한 단계만 보여 줍니다. 큰 버튼, 명확한 대비, 짧은 한국어와 문자 레이블을 사용합니다.
실제 학생정보, 로그인, 서버 DB, 유료 API를 사용하지 않습니다.
출력: Stitch용 한국어 요청문, 같은 뜻의 영어 요청문, 교사 점검표 5항목.
공인 인증·NEIS 연동·직무연수 학점·접근성 인증·암호화 보장을 만들어 넣지 마세요.

[2. Stitch: 새 수업 화면 제작]
앱 이름은 차츰차츰입니다. 다음 세 화면을 반응형 웹으로 설계해 주세요.
① 시작: 활동 목표와 ‘시작’ 버튼.
② 활동: 책 넣기 → 필통 놓기 → 책상 확인을 한 단계씩 표시하고, 이전·다음 버튼 제공.
③ 완료: ‘다시 해 보기’ 버튼과 첫 화면 이동.
모든 학생용 문구는 한국어, 큰 버튼·짧은 문장·명확한 대비를 사용하세요.
가능하면 브라우저에서 실행 가능한 정적 HTML/CSS/JavaScript로 연결하세요.
빌드 도구·서버·로그인·유료 API 없이 실행하는 것이 목표입니다.
화면 연결과 버튼 동작이 미구현이면 명확히 표시하세요. 만들어진 시안만으로 기능 완성을 주장하지 마세요.
실제 학생정보를 입력받지 마세요. 공인 인증·NEIS·학점·보안 인증·가짜 후기 등을 추가하지 마세요.
내보낸 파일에서 첫 진입 파일과 필요한 자산을 알려 주세요.

[3. Stitch 수정]
두 번째 화면의 ‘다음’ 버튼을 크게 하고 짧은 한국어로 안내해 주세요.
기존 화면과 나머지 동작은 유지하세요. 바뀐 부분과 미구현 동작을 알려 주세요.

[4. 선택: 학생 배지 화면 추가]
기존 화면은 유지하고 가상 학생 A/B용 교사 평가 화면과 학생 배지함을 추가해 주세요.
배지 ① 하루 한 걸음: 순서 확인/한 활동 선택·시도/다음 활동 확인.
배지 ② 마음을 전했어요: 마음·요구 선택/편한 방법으로 전달/의미 확인·다시 선택.
배지 ③ 생활을 해냈어요: 단계 확인/도움을 활용한 시도/다음 단계·재시도.
각 기준은 스스로/그림·말 단서 후/함께·도움 받아 수행/미관찰로 기록합니다.
도움은 감점·실패가 아닙니다. 세 기준 관찰, 관찰 근거, 교사 승인 전에는 발급하지 않도록 설계하세요.
블록체인 없이 현재 브라우저 시연으로 표시하고 실제 발급 동작의 구현 여부를 구분하세요.
교사 배지는 별도로 https://sedunet.sp000001.chatgpt.site/teacher-badges 에서 신청·심사합니다.
배지명: AI 특수교육 수업설계 실천. 한국교육연구소 기관 교육활동 배지이며 국가자격·학점·NEIS 인증이 아닙니다.

[5. Netlify 배포 전 점검]
내보낸 폴더에 index.html과 연결된 CSS·JS·이미지가 있는지 확인합니다.
직접 실행해 시작 → 다음 → 완료 → 다시 시작이 되는지 확인합니다.
작동하지 않거나 빌드 프로젝트만 나오면 준비된 실습 ZIP의 web 폴더로 배포 실습을 진행합니다.
Stitch 원본 자동 동기화나 버튼 구현을 기다리느라 8분 이상 멈추지 않습니다.
Netlify Free 로그인 → https://app.netlify.com/drop → 사이트 폴더 업로드 → 공개 상태 확인 → 다른 창·동료 기기로 확인.
GitHub 가입은 선택입니다. 기존 강사 사이트를 덮어쓰지 말고 본인 프로젝트로 게시합니다.
