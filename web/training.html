무료 ChatGPT → Stitch 설계 → Netlify Free 배포 → 활동평가와 배지 체험

실제 학생정보를 입력하지 않는 가상자료 시연입니다. Stitch의 화면 시안과 작동하는 사이트는 구분합니다. 교사 배지는 기관 교육활동 배지이며 학점·NEIS·국가자격 인증이 아닙니다.

1. 실습 파일 받기

실습 ZIP 내려받기복사용 요청문 받기

압축을 풀고 web 폴더를 Netlify Drop에 올립니다. web 폴더 안에 index.html이 있어야 합니다. README와 시작 배치파일이 있는 상위 폴더는 올리지 않습니다. ZIP에는 학생 기록이 들어 있지 않습니다.

2. 준비된 기능 체험

나의 하루 · 말로 전하기 · 교사 편집 · 학생 배지 평가·발급

학생 배지는 같은 브라우저의 가상 학생 A/B에게 발급합니다. 다른 기기나 세듀넷에 자동 전송되지 않습니다. 연습 기록을 새로 고치고 싶으면 가상 학생 B를 선택하거나 기존 배지를 사유와 함께 취소합니다.

3. Stitch에 입력할 기본 요청문

앱 이름은 차츰차츰입니다. 책상 정리 수업용 웹 화면을 설계해 주세요.
처음 → 단계 안내 → 완료·다시 시도의 세 화면입니다.
단계 안내는 책 넣기, 필통 놓기, 책상 확인을 한 번에 하나씩 보여 주세요.
큰 버튼, 명확한 대비, 짧은 한국어와 이전·다음·다시 시작을 사용하세요.
가능하면 빌드 없는 정적 HTML/CSS/JavaScript로 동작하게 연결하세요.
미구현 동작을 알려 주세요. 실제 학생정보·로그인·서버 DB·유료 API는 제외합니다.
공인 인증·학점·NEIS 연동·보안 인증·가짜 후기를 만들어 넣지 마세요.

4. 무료 배포 실습

  1. Netlify에 로그인해 Free 플랜과 잔여 사용량을 확인합니다. 가입은 미리 완료하세요.
  2. Stitch 결과를 내보내 확인합니다. 연결이 없거나 빌드가 필요하면 제공한 ZIP의 web 폴더를 사용합니다.
  3. Netlify Drop에 사이트 폴더를 올립니다. GitHub는 필요하지 않습니다.
  4. 게시·공개 상태와 netlify.app 주소를 확인하고, 별도 창과 동료 기기에서 열어 봅니다.
  5. 문구 한 곳을 수정하고 같은 프로젝트에 폴더를 다시 올려 원래 주소에서 확인합니다.

무료 플랜은 한도가 있습니다. 최초·수정 배포 각 1회로 연습하고 유료 도메인·AI 추가 기능을 사용하지 않습니다. 외부 그림·글꼴 일부는 인터넷이 필요합니다. 접속·생성 문제로 8분 이상 멈추면 제공한 파일로 배포 실습을 계속합니다.

5. 교사 배지 신청

수업 화면, 평가 루브릭, 가상 학생 배지 사례, 동료 의견을 반영한 수정·성찰의 네 근거를 준비합니다. 본인이 동의하고 신청한 뒤 운영자가 각 항목을 심사합니다. 네 항목 모두 충족(2)이고 승인하면 발급합니다. 참석만으로 자동 지급되지 않으며 현장에서 즉시 발급을 보장하지 않습니다.
