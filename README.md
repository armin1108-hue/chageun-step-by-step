# 차근차근 · 특수교육 배움 도우미

KERI(한국교육연구소)의 AI활용교육전문가 6기 1급 4일차 수업용 웹앱입니다. 기존 **Google Stitch 디자인 → 기능 보완 → GitHub 공유 → Netlify 배포**를 시연하기 위해 준비했습니다.

공개 웹앱: https://chageun-step-by-step.netlify.app/

GitHub 저장소: https://github.com/armin1108-hue/chageun-step-by-step

원본 Stitch 프로젝트: https://stitch.withgoogle.com/projects/11878761854160808095?pli=1

## 실행 가능한 기능

- 학생용 여섯 화면 사이 이동: 처음, 나의 하루, 마음 전하기, 말로 전하기, 생활 연습, 쉬어 가기.
- 나의 하루 5개 일과 체크, 취소, 전체 초기화. 같은 브라우저에서 새로고침해도 체크 기록 유지.
- 감정 선택, 크게 보여주기, 한국어 음성 읽기. 다시 선택한 뒤 이전 감정을 읽지 않도록 보완.
- AAC 그림 카드로 문장 만들기·삭제·한국어 읽기.
- 손 씻기 연습 완료 횟수 저장, 호흡 애니메이션, 브라우저에서 만든 합성 휴식 소리.
- `teacher.html`에서 실제 시연 활동 기록 확인, CSV 내려받기, 기록 초기화.

## 적용 범위

**수업용 데모입니다.** 실제 학생정보를 입력하지 마세요. 기록은 접속한 브라우저의 localStorage에 저장됩니다. 계정 로그인, 다른 기기와 동기화, 학교 DB 연동, 실제 교사 알림, IEP 자동평가, 접근성 인증, 데이터 암호화는 구현되어 있지 않습니다. 브라우저 저장정보를 지우면 기록도 지워집니다.

음성 읽기는 기기에서 지원하는 한국어 TTS를 사용하며, 합성 휴식 소리는 자연 녹음 파일이 아닙니다. 디자인에는 Google Fonts, Tailwind CDN, Stitch에서 생성된 외부 이미지가 쓰여 인터넷 연결이 필요합니다. 양치·옷 입기·자리 정리 등 추가 활동은 디자인 예시라고 화면에서 안내합니다.

`source/stitch/`에는 확보한 학생·교사·학부모 원본 디자인 12개를 보관했습니다. 이 원본에 있는 가상 학생명·예시 수치·보안/인증 문구는 사실로 검증된 결과가 아닙니다. **실제 배포에는 `web/` 파일만 포함되며 원본 디자인 자료는 배포하지 않습니다.** 원본 획득 방법은 `source/provenance.json`에 기록했습니다.

## 로컬 확인

Node.js 22 이상에서 실행합니다. 외부 npm 의존성이 없습니다.

```bash
npm test
npm run build
python -m http.server 8000 --directory dist
```

브라우저에서 http://localhost:8000 에 접속합니다.

## Netlify로 배포

1. Netlify의 팀 **esg initiative (`armin1108`)**에 로그인합니다.
2. **Add new project → Import an existing project → GitHub**를 선택합니다.
3. `armin1108-hue/chageun-step-by-step` 저장소를 선택합니다. 저장소가 안 보이면 GitHub App의 접근 범위를 확인합니다.
4. 배포 브랜치는 `main`, Base directory는 비워 둡니다.
5. Build command는 `npm run build`, Publish directory는 `dist`입니다. `netlify.toml`에 같은 설정이 들어 있습니다.
6. 공개할 코드·이미지·정보 범위를 검토한 뒤 Deploy를 실행합니다.
7. 성공한 배포 URL을 PC·휴대폰에서 열고 아래 확인을 수행합니다.
8. 이후 `web/` 파일을 GitHub에서 수정하고 `main`에 커밋하면 Netlify가 자동으로 새 빌드를 실행합니다.

`.netlify/`는 `.gitignore`에 등록되어 있어 연결 상태 파일을 GitHub에 올리지 않습니다. 원본 디자인 전체를 공개하는 것과 웹앱만 배포하는 것은 별도의 공개 범위입니다.

## 배포 후 확인

1. 홈에서 여섯 메뉴가 이동하는지 확인합니다.
2. 일과 두 개를 체크한 뒤 새로고침하여 `2/5`가 유지되는지 확인합니다.
3. 감정을 선택하고 크게 보기·음성 읽기를 실행합니다. 다시 선택을 누르면 기존 감정이 읽히지 않아야 합니다.
4. AAC 카드 두 개를 선택해 문장을 읽고 하나를 지웁니다.
5. 생활 연습 완료 후 시연 기록에 횟수와 활동이 나타나는지 확인합니다.
6. 호흡 시작·멈춤, 합성 소리 시작·멈춤·음량을 확인합니다.
7. 시연 기록 CSV를 내려받고 초기화합니다.

## 수업에서 보여줄 순서

`docs/4일차_실습서.md`에 강사 시연·개인 개발 과제·학습동아리 제출·2주 후속 안내를 포함한 상세 실습 순서가 있습니다. 학습자는 GitHub 주소, Netlify 배포 주소, 사용법 3줄, 동작 화면 1장, 다음 개선점 1개를 학습동아리 방에 올립니다.

정적 빌드와 JavaScript 구문 검사, 브라우저 저장·손상 복구·CSV·초기화 자동 검사를 통과했습니다. 2026-10-09 공개 Netlify에서 화면 이동, 일과 2개 체크 후 새로고침 유지, 감정 선택·크게 보기·다시 선택, AAC 2개 카드 조합·한 카드 삭제, 생활 연습 기록, 호흡 시작·멈춤, 합성 소리 재생 상태·음량, 시연 기록 반영과 CSV 다운로드를 확인했습니다. 한국어 음성 품질은 기기별 별도 확인이 필요합니다. GitHub 커밋 뒤 Netlify 자동 재배포도 확인했습니다.
